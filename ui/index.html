🗺️ نقل المشروع وخريطة العمل

نسخة مستقلة من ملفات المشروع مع ملخص Git والخطوات المتاحة في سجلات Claude Code أو Codex. ليست تسجيلًا حيًا لكل خطوة، ولا تحويلًا للمحادثة إلى صيغة البرنامج الآخر. لن يتغير المشروع الأصلي. لا يشمل مفاتيح أو اعتمادات إلا بموافقتك الصريحة أدناه.

ملاحظة مهمة

لا يشمل هذا النقل مفاتيح API أو الاعتمادات الحساسة بشكل افتراضي. تأكد من مراجعة الملفات الناتجة قبل استخدامها في البرنامج الآخر.

يُستبعد Git الداخلي والاعتماديات وملفات البيئة والمفاتيح المعروفة. الاستبعاد بالاسم ليس ضمانًا لخلو الكود من أسرار؛ راجع الملفات قبل مشاركتها. الحزمة محلية وغير مشفّرة.

Token Guard
Local project detection, advisory rules, and reusable summaries for AI coding tools.


                

                    
                    
StrLink is a separate program from Claude Code, Codex, and Gemini and cannot see or control what they actually send to their models - no outside program can. Token Guard only writes advisory instructions and local, mechanically-generated summaries that those tools may read as ordinary project files, so they don't have to re-explore the project from scratch.
